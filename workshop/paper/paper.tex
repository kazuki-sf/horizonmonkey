\title{Retrieval Relevance Is Not Verification Priority:\\
Budgeted Provenance Checking in Inherited Agent Memory}

\author{Anonymous}

\begin{abstract}
A memory system that gives every record a provenance link is not thereby safe.
An agent inheriting hundreds of consolidated beliefs can follow only a few links
before it acts, so the safety-critical question is not whether provenance exists
but which links get followed. We study that allocation directly. In a controlled
environment where exactly one of six inherited memories has lost a true negative
caveat, and the agent may pull at most $k$ source records before committing, we
find allocation is governed by the agent's own plan: across \ExpOneN{}
pre-registered episodes the corrupted memory is verified in \AlignedK/\AlignedN{}
episodes whose first-pass intent it backs and \MisK/\MisN{} otherwise --- complete
separation, no counterexample. Two new pre-registered experiments then establish
that this allocation causes later behaviour rather than merely correlating with
it. Randomising which source records are carried into a later decision, after the
budget is spent and the situation has shifted, moves the corrupted-direction rate
from \ThreeBOthK/\ThreeBOthN{} to \ThreeBTgtK/\ThreeBTgtN{} --- $\ThreeBDiff$
points pooled, and the same direction in all \ThreeBAllModels{} models. A third experiment separates what drives
allocation from what the memory means: with the agent's plan held fixed, a
memory carrying an \emph{irrelevant} hedge is checked more often than the
same memory with its caveat silently deleted, so omission is stealthier than
qualification. Finally, we test the premise the threat model rests on by running
a real consolidation chain, and it fails: over six generations of
re-summarisation, quantified negative outcomes mostly survive (\FiveNegResDPct\%
of chains at the tightest compression, \FiveNegPerModelLo{} to
\FiveNegPerModelHi{} per model), while scope restrictions and normative
prohibitions erode. The corruption that matters is loss of the constraint,
not loss of the fact. We argue persistent-memory systems need a
verification scheduler distinct from the retriever, and that the two rank
records differently.
\end{abstract}

\section{Introduction}

Long-horizon agents do not reason from evidence. They reason from memory:
lessons written by earlier sessions, compressed by consolidation passes, and
inherited as durable organisational knowledge. Provenance-aware memory designs
answer this by keeping a link from every consolidated record back to its source,
so a suspicious belief can be checked.

That defence has a budget. An agent that inherits hundreds of beliefs and must
act this cycle can follow two or three links, not two hundred. Whether the
memory system is safe therefore depends on a decision the retrieval layer never
makes: given many records that could have drifted and no labels saying which
did, \emph{which records does the agent choose to audit?}

This is a ranking problem, and it is not the ranking a retriever computes. A
retriever ranks by relevance to the current query or plan. What an audit should
rank by is the expected cost of the record being wrong --- which is often
highest exactly where the agent is \emph{not} currently looking, because a
belief the agent is about to act on will be tested by acting, while a belief
sitting quietly in memory will not.

We study this gap in a controlled setting. An agent inherits six length-balanced
lessons, one of which has lost a true, materially negative caveat during
consolidation. It may retrieve at most $k$ source records before committing to
an action. Because we removed the caveat, we know exactly which lookup recovers
it, and every allocation is scored against that ground truth. The corrupted
belief is deliberately \emph{not} the one the situation makes salient: the
symptoms point toward onboarding work, while the corrupted memory recommends
promotional pricing.

\paragraph{Contributions.}
\begin{enumerate}\itemsep2pt
\item \textbf{Problem formulation.} Budgeted selective verification over
inherited memory as a reliability variable distinct from retrieval and from
detection (\S\ref{sec:setup}).
\item \textbf{Measurement.} Verification allocation is governed by the agent's
current intent, with complete separation over \ExpOneN{} pre-registered episodes
(\S\ref{sec:alloc}).
\item \textbf{Causal identification.} Two pre-registered experiments --- a
randomised-instrument replay and a randomised carry-forward --- show that what
the budget recovered \emph{causes} the later decision, with the confounds of the
observational design removed by construction (\S\ref{sec:causal}).
\item \textbf{Mechanism.} With intent held fixed, allocation responds to
unresolved qualification, and a silently deleted caveat attracts \emph{less}
scrutiny than an irrelevant hedge (\S\ref{sec:qualifier}).
\item \textbf{A negative result that reframes the threat model.} Real
consolidation does not produce the corruption this literature assumes. Over six
generations, quantified negatives survive; prohibitions erode
(\S\ref{sec:drift}).
\end{enumerate}

Study~1 (\S\ref{sec:alloc}) re-analyses episode files released with an earlier
preprint by the same authors; the citation is omitted here for anonymity and
will be restored in the camera-ready. Studies~2--4 are new, pre-registered
before any model call, and reported with their failures.

\section{Related work}

\paragraph{Memory integrity.} Memory-poisoning work studies adversarial
insertion into agent memory \citep{dash2026untrusted,xie2026memevobench} and
defences that trust sources rather than content \citep{singh2026belief}.
Our corruption is not adversarial: nothing false is inserted, and the drifted
summary is what a benign compression pass produces. The threat model is
operational, extending fault injection \citep{tan2026agentchaos} from transport
faults to the semantic layer.

\paragraph{Budgeted verification.} A growing line allocates limited verification
compute across candidate \emph{outputs} or reasoning steps
\citep{yuan2026belief,fang2026budget,yang2026hetero}, and benchmarks ask whether
agents manage tool budgets at all \citep{wang2026allocbench,lin2026bagen}. We allocate over \emph{inherited
beliefs} and measure the direction of the allocation rather than its total.

\paragraph{Provenance and self-auditing.} Execution-provenance surveys catalogue
how evidence and actions connect in agent traces \citep{wang2026traces};
self-auditing repairs unsupported intermediate beliefs \citep{yuan2026verify},
and provenance-sensitivity audits ask whether action selection responds to
source information at all \citep{liao2026auditing}. These assume the audit target is given, or
audit everything. We study the upstream selection problem.

\paragraph{Positive test strategies.} That an agent checks the evidence behind
its favoured hypothesis rather than evidence that could overturn it rhymes with
human hypothesis-testing research \citep{wason1960,klayman1987}. We claim no shared mechanism; we claim the
allocation signature is measurable and steerable in agents.

\section{Setup}\label{sec:setup}

A growth agent for a synthetic B2B SaaS business inherits six durable memories,
each a one-to-two-sentence lesson with a consolidation date and an archived
source. Bodies are length-balanced (\BodyMin--\BodyMax{} characters) and identically
formatted; presentation order is shuffled per episode with a seeded PRNG. The
situation presents three concurrent symptoms so that four of the six memories
bear on something and no action trivially dominates. The agent may retrieve at
most $k$ source records by id, then commits to one action. Six models from two
providers are used throughout, at their default or medium reasoning setting,
with byte-identical prompts and structured output enforced.

In the \emph{clean} arm the target memory carries its true caveat; in the
\emph{drifted} arm the caveat is absent and the remaining sentence is still
true. A \emph{triage} arm adds one system-prompt sentence: \textit{when
verification capacity is limited, prioritize inherited beliefs that are both
highly consequential to the current decision and insufficiently supported for
the objective being optimized}. It names no memory, metric, or direction.

\section{Study 1: allocation follows intent}\label{sec:alloc}

Across all \ExpOneN{} episodes --- every condition, budget, target and model ---
the corrupted memory is verified in \textbf{\AlignedK/\AlignedN{}} episodes
whose first-pass intended action it backs, against \MisK/\MisN{} (\MisPct\%)
otherwise. The relation is completely separated: the corpus contains no episode
in which the agent planned to act on the corrupted belief and did not check it.

Table~\ref{tab:unified} fits one model to all \ExpOneN{} episodes. Because
intent-alignment separates the outcome perfectly the ordinary MLE diverges, so
we use Firth's penalised likelihood; the separation is the finding, not a
nuisance. Target position carries an odds ratio of $\ORPos$, confirming that
randomising presentation order removed it as a confound.

A uniform policy at $k{=}2$ over six memories reaches the target 33\% of the

The aggregate hides the structure: allocation is not weakly risk-sensitive, it
is strongly plan-sensitive.
